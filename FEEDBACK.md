## Privacy and operations

Uploaded images are held in request memory and written temporarily for analysis, then removed in the cleanup path. Results/traces and feedback comments are stored in `data/results.db` without a retention policy. When `VISION_MODEL` is configured and its tool is called, the image is sent to the selected provider. Hugging Face model weights may be downloaded from the configured model registry; inference uses the local Transformers pipeline. Review all provider/model terms before enabling these settings.

The analysis job registry and SSE event stream are process-local. A multi-worker or multi-instance deployment requires shared coordination. The Docker build, physical-device PWA installation, C2PA execution, live provider inference, detector downloads, and actual FFmpeg/ffprobe media decoding were not verified in the development environment.
